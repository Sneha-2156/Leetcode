## ▶️ Run Locally

These solutions use LeetCode's `Solution` class submission format. To run one outside LeetCode, place the code in a local Java project, add any required imports, and create a small driver with a `main` method and test cases.

```bash
# Check your Java installation
java -version
javac -version

# Compile and run your local driver
javac Main.java
java Main
```
