## About this repository

This repository brings together my Java implementations of algorithmic problems from LeetCode. It is organized as a practical reference to approaches, data structures, and algorithmic techniques that are relevant to writing reliable and efficient software.

My focus is on more than reaching an accepted submission: I aim to choose appropriate data structures, reason about edge cases, evaluate complexity, and keep solutions clear and maintainable.

## Engineering focus

The problems in this repository exercise several core areas of computer science:

- **Data structures:** arrays, hash maps, and ordered maps.
- **Algorithm design:** greedy reasoning, sorting, and dynamic programming.
- **Problem-solving patterns:** two pointers, sliding windows, and median-based optimization.
- **Efficiency analysis:** time and auxiliary-space complexity, including the trade-offs between alternative approaches.
- **Implementation quality:** readable Java, careful handling of constraints, and attention to edge cases.

## Implementation notes

Solutions are written in Java using LeetCode's `Solution` class format. Each problem directory contains its implementation and a problem-specific explanation.

For local execution, use a JDK and create a small driver class with test cases. The LeetCode submission files may need imports or a local test harness when run outside the platform.
